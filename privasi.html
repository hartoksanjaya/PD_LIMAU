Kebijakan Privasi

Padang Limau Negeri Indah - Aplikasi Display Only

Tanpa Pengumpulan Data Pengguna
Terakhir Diperbarui: 30 Mei 2026

1. Ringkasan Penting

Aplikasi Padang Limau Negeri Indah adalah aplikasi "Display Only". Kami tidak mengumpulkan, menyimpan, memproses, atau membagikan data pribadi pengguna dalam bentuk apapun.

2. Data yang TIDAK Kami Kumpulkan

Aplikasi ini tidak meminta atau mengakses:

  • ❌ Nama, email, nomor telepon, atau identitas pribadi
  • ❌ Lokasi geografis atau GPS
  • ❌ Kontak, foto, atau file perangkat
  • ❌ Riwayat browsing atau aktivitas aplikasi lain
  • ❌ Data analitik pelacakan pengguna
  • ❌ Cookie pelacakan atau fingerprinting

3. Data yang Mungkin Tersimpan (Lokal Saja)

Untuk fungsionalitas offline, Service Worker dapat menyimpan:

  • ✅ File HTML, CSS, JavaScript (kode aplikasi)
  • ✅ Gambar dan aset visual (ikon, foto destinasi)
  • ✅ Data manifest PWA

Catatan: Semua data di atas disimpan hanya di perangkat Anda melalui Cache API browser. Data tidak dikirim ke server manapun dan dapat dihapus kapan saja melalui pengaturan browser.

4. Koneksi Eksternal

Aplikasi memuat aset dari sumber eksternal berikut untuk fungsionalitas tampilan:

  • Google Fonts: Untuk tipografi (fonts.googleapis.com)
  • Font Awesome: Untuk ikon (cdnjs.cloudflare.com)
  • Unsplash: Untuk gambar placeholder (images.unsplash.com)
  • Google Maps: Untuk peta embed (google.com/maps)

Kami tidak menambahkan parameter pelacakan pada permintaan ke layanan tersebut. Untuk informasi lebih lanjut, silakan baca kebijakan privasi masing-masing penyedia.

5. Izin Aplikasi

Aplikasi ini tidak meminta izin khusus seperti:

  • 📍 Akses lokasi
  • 📷 Kamera atau mikrofon
  • 📁 Penyimpanan eksternal
  • 🔔 Notifikasi push
  • 👥 Kontak atau kalender

6. Keamanan

Karena tidak ada data pengguna yang dikumpulkan, tidak ada risiko kebocoran data pribadi melalui aplikasi ini. Aplikasi di-host dengan enkripsi HTTPS untuk mengamankan transmisi konten.

7. Hak Pengguna

Karena kami tidak menyimpan data Anda, hak-hak berikut secara otomatis terpenuhi:

  • ✅ Hak untuk mengakses data: Tidak ada data yang perlu diakses
  • ✅ Hak untuk memperbaiki data: Tidak berlaku
  • ✅ Hak untuk menghapus data: Hapus cache browser jika diinginkan
  • ✅ Hak untuk membatasi pemrosesan: Tidak berlaku
  • ✅ Hak untuk portabilitas data: Tidak berlaku

8. Perubahan Kebijakan

Jika di masa depan kami memutuskan untuk menambahkan fitur yang memerlukan data (dengan persetujuan eksplisit), kami akan:

  • Memperbarui kebijakan ini dengan jelas
  • Meminta persetujuan Anda sebelum mengaktifkan fitur tersebut
  • Memberikan opsi untuk menonaktifkan atau menghapus data
